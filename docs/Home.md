# Starlet

GameCube and Wii compatibility layer for Linux ARM handhelds. For building it and using it
in a port, see the [README](https://github.com/Producdevity/starlet#readme).

- [GX model](GX-model.md): the GX command core, its hardware behaviour and sources
- [GLES renderer](GLES-renderer.md): context and threads, EFB copies, snapshots, write-backs, direct submission
- [OS and GX FIFO](OS-and-GX-FIFO.md): guest threads, interrupts, FIFO, draw sync, VI and EFB peeks
- [SDK services](SDK-services.md): AI, AX, DVD, PAD, ARAM, NAND, THP and the compat headers
- [Host services](Host-services.md): SDL audio, controllers and quit
- [Discs and memory cards](Discs-and-memory-cards.md): disc images, first-launch setup and memory cards
- [Aurora integration](Aurora-integration.md): Starlet as the renderer of an Aurora GLES port
- [Replay traces](Replay-traces.md): recorded GX traces, the replay suite and its references
